# Third-Party Licenses

This repository currently does not bundle model files, SDK packages, or prebuilt native binaries.

Flutter and Dart dependencies are resolved through the Flutter toolchain and `pubspec.yaml`.
Their licenses should be reviewed from the dependency metadata generated by the toolchain for release builds.

Future integrations will require explicit license review before inclusion:

- Stack-chan protocol/client code
- ReazonSpeech ASR
- Piper Plus TTS
- OpenAI compatible API clients
- OpenAI API optional client code
- llama.cpp
- LiteRT-LM CPU/GPU
- Face and voice recognition components
- Android Foreground Service support libraries

Any future model, SDK, or binary dependency must be documented here before release.
