# iPhone / TestFlight Beta

[Back to README](../../README_en.md) | [日本語](../ja/ios-testflight.md)

## 1. Install TestFlight

Install Apple's `TestFlight` app from the App Store.

## 2. Open the Beta Link

Open the shared TestFlight public link on your iPhone.

https://testflight.apple.com/join/Tt1Z4xpT

## 3. Install StackChan Pet Talk

Install `StackChan Pet Talk` from TestFlight.

## 4. Launch the App

The app may ask for permissions on first launch. Review the purpose and allow the permissions you need.

Permissions that may be used:

- Local network: required to connect to the Stack-chan device
- Camera/photos: used only when optional image or visual features are used

## 5. Connect to Stack-chan

Follow [Getting Started](getting-started.md) to connect to the Stack-chan device.

## 6. Send Feedback

Please report bugs, connection failures, unclear screens, or unexpected behavior through TestFlight feedback or the contact method shared by the distributor.

Useful details:

- iPhone model
- iOS version
- Connection mode: SoftAP / Wi-Fi IP
- What you were doing
- Error messages or screenshots

## 7. TestFlight Notes

TestFlight is Apple's beta distribution system. This is not a production release, so bugs, crashes, behavior changes, and beta expiration may occur.

The distributor may be able to view information needed to manage the beta and respond to feedback in App Store Connect. This may include invitation or participation status, feedback submitted through TestFlight, and crash information.

The distributor uses this information only for beta operation, issue investigation, and app improvement. It is not used for unrelated purposes.

The public TestFlight link may stop working when the tester limit is reached or the beta period ends.

For detailed app usage, see the [Full User Guide](../user_manual_en.md).
