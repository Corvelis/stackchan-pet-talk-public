# リリースノート

[READMEへ戻る](../../README.md) | [English](../en/release-notes.md)

## 1.0.6 (48)

- 対応するStopWatchからスマートフォンのカメラをリモート撮影できるようになりました。
  イン／アウトカメラを切り替え、撮影した写真を次のテキストまたは音声会話へ
  自動的に添付できます。
- llama.cpp VLMで画像選択後の先行処理とKVキャッシュに対応し、画像付き会話の
  応答開始を高速化しました。
- 会話ストリーミング表示の更新処理を改善し、長い返答をより滑らかに表示できる
  ようにしました。
- Androidでは、対応するQualcomm Adreno端末でllama.cppのOpenCL GPUバックエンドを
  利用できるようになりました。非対応端末や初期化に失敗した場合はCPUへ自動的に
  フォールバックします。
- iOSでは、llama.cppのMetalバックエンドでTQ2_0量子化モデルの処理に対応しました。
- ローカルLLMがCPUとGPUのどちらで動作しているか確認できる表示と診断情報を
  改善しました。

### 利用時の注意

- StopWatchリモート撮影には対応ファームウェアが必要です。OSの制約上、
  スマートフォンアプリが前面にある場合だけカメラ画面を自動表示できます。
- GPU対応状況と性能は端末、モデル、量子化方式によって異なります。
- ローカルLLM/VLMを使う場合は、対応するGGUF、mmproj、またはLiteRT-LMモデルを
  利用者が用意してください。

詳しい操作方法は [使い方ガイド](user-manual.md) を確認してください。
