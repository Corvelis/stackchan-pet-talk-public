# iPhone / TestFlight 参加方法

[READMEへ戻る](../../README.md) | [English](../en/ios-testflight.md)

## 1. TestFlightをインストールする

App Store から Apple の `TestFlight` アプリをインストールします。

## 2. ベータ版リンクを開く

配布された TestFlight 公開リンクを iPhone で開きます。

https://testflight.apple.com/join/Tt1Z4xpT

## 3. StackChan Pet Talkをインストールする

TestFlight の画面で `StackChan Pet Talk` をインストールします。

## 4. 初回起動する

初回起動時に権限の確認が表示される場合があります。表示内容を確認して、必要な権限を許可してください。

主に使う可能性がある権限:

- ローカルネットワーク: ｽﾀｯｸﾁｬﾝ本体へ接続するため
- カメラ/写真: 任意の画像や視覚機能を使う場合

## 5. ｽﾀｯｸﾁｬﾝ本体へ接続する

[初回セットアップ](getting-started.md) の手順に沿って、ｽﾀｯｸﾁｬﾝ本体に接続してください。

## 6. 新しいベータ版で確認してほしいこと

- SoftAP 接続を維持したまま、モバイルデータ経由で外部 LLM / ASR / TTS / Hermes API を利用できるか
- 対応デバイスでストップウォッチ、タイマー、ポモドーロ、ピタリモードの発話が重複せず、適切なタイミングで再生されるか
- 画面OFFから戻した時に、対応デバイスとの通信が正常に再開するか
- Hermes Agent の接続確認、ツール進捗、会話履歴、画像添付が動作するか
- 思考対応モデルで、思考過程が折り畳み表示され、最終回答だけが読み上げられるか

機能別の手順は [時間機能の発話](timekeeper.md) と [Hermes Agent の使い方](hermes-agent.md) を確認してください。

## 7. TestFlight利用時の注意

TestFlight はベータ版アプリを配布するための Apple の仕組みです。正式公開版ではないため、不具合、クラッシュ、仕様変更、テスト期間の終了が発生する場合があります。

配布者は App Store Connect 上で、テスター管理とフィードバック対応に必要な範囲の情報を確認できる場合があります。たとえば、招待や参加状況、TestFlight 経由で送られたフィードバック、クラッシュ情報などです。

配布者は、これらの情報をベータテストの運用、不具合調査、改善のためにのみ利用します。不要な目的で利用することはありません。

TestFlight の公開リンクは、参加上限やテスト期間により利用できなくなる場合があります。

詳しい操作方法は [詳しい操作手順](user-manual.md) を確認してください。
