# 思い出と日記の使い方

最終更新日: 2026-07-20

`StackChan Pet Talk` は、会話、写真、なでなで、マスター認識などの記録を「思い出」として保存し、選択した日の内容から ｽﾀｯｸﾁｬﾝ 視点の日記を作れます。

日記は実装を意識せずに使えますが、LLM、ログ量、プロンプト設定によって出力の雰囲気が変わります。このページでは、日記画面の使い方と設定で調整できる範囲を説明します。

## 1. 日記でできること

- カレンダーから日付を選び、その日の思い出を確認する
- 会話ログ、写真メモ、なでなで、マスター認識などを日記材料にする
- 対応する ｽﾀｯｸﾁｬﾝ から届いたその日の歩数を確認する
- LLM を使って、ｽﾀｯｸﾁｬﾝ 本人の視点の日記を作る
- 作成済みの日記を表示する
- 作成済みの日記を作り直す
- 日記だけを削除する
- その日のログ、写真、日記をまとめて非表示にする
- 日記の書き方や事前要約のプロンプトを設定する

日記を作るには、対象日の会話または写真ログが5件以上必要です。足りない場合は、日記画面に必要な残り件数が表示されます。

## 2. 日記画面を開く

1. 会話画面を開きます。
2. 画面上部の `思い出` アイコンを押します。
3. カレンダーから見たい日付を選びます。
4. `日記`、`ログ`、`写真` のタブを切り替えて確認します。

カレンダーには、思い出ログがある日が表示されます。最初に開いた時は、設定されている日記の区切り時刻を基準にした「今日」が選ばれます。
対応する ｽﾀｯｸﾁｬﾝ から歩数が届いている場合は、その日の歩数も画面に表示されます。
歩数は現在、日記を作成するための5件のログには数えず、日記生成の材料にも含めません。

思い出と日記は、現在選択中のキャラクターにひもづきます。`設定 > ｽﾀｯｸﾁｬﾝ接続` の
`キャラ設定の管理` で `デバイス別` を使っている場合、接続先を切り替えると表示される思い出も
その端末のキャラクター分に切り替わります。

## 3. 日記を書く

選択した日に日記がまだない場合、`日記` タブに `日記を書く` ボタンが表示されます。

1. `思い出` 画面で日付を選びます。
2. `日記` タブを開きます。
3. `日記を書く` を押します。
4. LLM がその日の思い出から日記を作ります。

日記生成には現在の LLM 設定が使われます。外部 API を選んでいる場合は、日記材料やプロンプトがその API 提供元へ送信される場合があります。ローカル LLM を選んでいる場合は、端末上のモデルで生成します。

## 4. 作り直しと削除

作成済みの日記には、`作り直す` ボタンと削除ボタンが表示されます。

- `作り直す`: 現在の日記本文を新しい生成結果で上書きします。
- 削除ボタン: その日の日記だけを削除します。ログと写真は残ります。
- `ログ` タブの `この日の思い出を削除`: その日のログ、写真、日記をまとめて非表示にします。

日記を作り直すと、同じログでも LLM の設定やプロンプト、temperature などによって表現が変わることがあります。

## 5. ログと写真を見る

`ログ` タブでは、選択日の会話、なでなで、マスター認識、歩数などのイベントを
時系列で確認できます。

`写真` タブでは、思い出として保存された写真を確認できます。写真を開くと、詳細を
確認したり、端末の写真ライブラリへ保存したりできます。不要な写真は非表示にできます。

会話画面の画像ボタンから、スマートフォンのカメラ、写真ライブラリ、または対応する
ｽﾀｯｸﾁｬﾝ 本体のカメラ画像を次のメッセージに添付できます。写真権限やカメラ権限が
必要になる場合があります。

日記に写真を反映したい場合は、`設定 > 思い出と日記` の `撮影画像を思い出に保存する` をオンにしてください。写真そのものだけでなく、画像認識結果や写真メモのテキストが日記材料になります。

## 6. 自動生成

`設定 > 思い出と日記 > 日記を自動生成する` をオンにすると、日記の区切り時刻を過ぎたあと、未作成の日記を自動で作ります。

自動生成は、次の条件を満たす場合に動きます。

- 日記画面で過去の日付を開いている
- その日に日記がまだない
- 対象ログが5件以上ある
- LLM が使える状態になっている
- `日記を自動生成する` がオンになっている

すでに日記がある日は、自動生成で上書きしません。作り直したい場合は `作り直す` を押してください。

## 7. 日記の区切り

`設定 > 思い出と日記 > 日記の区切り` で、日記の日付を切り替える時刻を設定できます。

初期値は `04:00` です。たとえば区切りが `04:00` の場合、深夜 1:00 の会話は前日の日記に入ります。

夜遅くまで使う場合は、生活リズムに合わせて区切り時刻を調整してください。

## 8. マスターとの会話だけで日記を書く

`設定 > 思い出と日記 > マスターとの会話だけで日記を書く` をオンにすると、マスターまたは未判定の会話・写真だけを日記材料にします。

この設定は、マスター認識を使っている場合に便利です。ゲストとの会話を日記に含めたくない時に使います。

注意:

- 日記作成には、絞り込み後の対象ログが5件以上必要です。
- 未判定のログは対象に残ります。
- マスター認識が安定していない場合、想定したログが含まれないことがあります。

## 9. LLMで事前要約してから日記を書く

`設定 > 思い出と日記 > LLMで事前要約してから日記を書く` をオンにすると、日記本文を作る前に、その日のログを LLM で短く要約します。

オンの場合:

- 長いログでも日記生成に渡しやすくなります。
- ローカル LLM のコンテキスト上限に収まりやすくなります。
- 事前要約の品質によって、日記に残る出来事が変わることがあります。

オフの場合:

- 対象ログをなるべくそのまま日記プロンプトに渡します。
- ログが短い日は、より直接的に日記を書ける場合があります。
- ログが長い日は、ローカル LLM で失敗しやすくなる場合があります。

OpenAI API、Gemini API、OpenAI compatible API などの API 型 LLM では、ローカル LLM より長い入力を扱えることがあります。ローカル LLM では、モデルのコンテキストサイズを超えないように、ログを分割して事前要約する場合があります。

## 10. 日記プロンプトを調整する

`設定 > 思い出と日記` では、日記の書き方をプロンプトで調整できます。

設定できるプロンプト:

- `日記用の事前要約プロンプト`: ログを日記材料へまとめる時の指示です。
- `iOS/通常用の日記プロンプト`: iOS や API 型 LLM など、通常経路の日記本文生成で使います。
- `通常/API用の日記プロンプト`: Android で表示される通常/API用の日記本文生成プロンプトです。
- `Android LiteRT-LM用の日記プロンプト`: Android の LiteRT-LM で日記本文を作る時だけ使います。Android 端末でのみ表示されます。

プロンプトを変えると、日記の雰囲気、長さ、見出しの付け方、最後の一言の書き方が変わります。

迷った場合は `デフォルトに戻す` を押してください。現在の画面で使う日記プロンプトと事前要約プロンプトを初期値に戻します。

## 11. プロンプトで使える変数

プロンプトには、日記生成時に自動で置き換わる変数を使えます。

よく使う変数:

- `{characterName}`: 日記を書くキャラクター名
- `{characterStyle}`: 名前、一人称、好感度に応じた距離感をまとめた指示
- `{memoryMaterial}`: 日記本文に渡す主な材料
- `{memoryPreSummary}`: LLM による事前要約
- `{rawMemoryLogs}`: 対象ログの生ログ
- `{dailyEvents}`: 選択日の象徴的な出来事
- `{conversationHighlights}`: 会話の短いハイライト
- `{photoDescriptions}`: 写真メモや画像認識結果
- `{pettingSummary}`: なでなでやマスター認識の概要

`{memoryMaterial}` は、通常は一番扱いやすい変数です。事前要約がオンなら要約結果、オフなら対象ログが入ります。

`{rawMemoryLogs}` は情報量が多くなりやすいため、ローカル LLM では入力上限に注意してください。

## 12. 外部APIとプライバシー

外部 API の LLM を使う場合、日記生成に必要な情報が API 提供元へ送信される場合があります。

送信される可能性があるもの:

- 日記プロンプト
- その日の会話ログ
- 写真メモや画像認識結果
- キャラクター設定の一部
- 好感度に応じた書き方のヒント

画像そのものを送るかどうかは、利用している機能と LLM 設定によって変わります。日記では主に写真メモや画像認識結果のテキストを材料にします。

詳しくは [プライバシーポリシー](../../privacy/ja.md) も確認してください。

## 13. うまく日記が作れない時

`日記を書く` ボタンが押せない:

- 対象日の会話または写真ログが5件以上あるか確認します。
- `マスターとの会話だけで日記を書く` がオンの場合、絞り込み後の対象ログが足りない可能性があります。

日記の内容が薄い:

- `ログ` タブで、その日に十分な会話や写真があるか確認します。
- `LLMで事前要約してから日記を書く` をオンにして試します。
- プロンプトを変更している場合は `デフォルトに戻す` を試します。
- LLM 設定の temperature、topK、topP を調整します。

ローカル LLM で生成に失敗する:

- LiteRT-LM や llama.cpp のモデルファイルが正しく選ばれているか確認します。
- LLM のコンテキストサイズ、最大トークン数、temperature などを確認します。
- ログが多い日は、事前要約をオンにしてください。
- 一度モデルのウォームアップを試してください。

Markdown表示が崩れる:

- プロンプトを変更している場合は `デフォルトに戻す` を試します。
- Android LiteRT-LM では、Android専用の日記プロンプトを使うと表示が安定しやすくなります。

外部 API で生成されない:

- API キー、Base URL、モデル名を確認します。
- OpenAI compatible API をスマートフォン実機から使う場合、`localhost` ではなく PC の LAN IP を指定してください。
- API 提供元の利用制限や接続状態を確認してください。
