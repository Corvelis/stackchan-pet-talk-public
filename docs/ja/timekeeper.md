# 時間機能の発話

[READMEへ戻る](../../README.md) | [English](../en/timekeeper.md)

対応ファームウェアを使うと、Stack-chan のストップウォッチ、タイマー、ポモドーロ、10秒当て（ピタリモード）の進行や結果を、アプリで設定したキャラクターと音声で読み上げられます。

## 必要なもの

- `timekeeper.v1` に対応する Stack-chan または StopWatch ファームウェア
- Stack-chan とアプリの接続
- アプリで設定済みの TTS。`音声なし` の場合は読み上げません
- ポモドーロ時間をアプリから変更する場合は `timekeeper.pomodoro.v1` 対応ファームウェア

時間機能の読み上げは、通常の会話と同じキャラクターと TTS を使います。読み上げ内容は会話履歴、思い出、日記の材料には追加されません。

## 設定する

`設定 > ストップウォッチ発話` を開きます。

- `時間機能の発話`: すべての時間機能の読み上げを有効または無効にします。
- `発話量`: `静か`、`標準`、`にぎやか` から選びます。終了や結果など重要な通知は、静かな設定でも読み上げる場合があります。
- `ミリ秒まで読み上げる`: ラップや結果を細かく読み上げます。
- `同じ台詞を続けて使わない`: 候補が5種類以上ある場面で、直近2件を避けて選びます。
- `使用する音声`: 通常会話と共通の TTS 設定を確認または変更します。

## 話す言葉を変更する

`設定 > ストップウォッチ発話 > 話す言葉の設定` では、ストップウォッチ、タイマー、ポモドーロ、ピタリモードの場面ごとに台詞を追加、編集、削除できます。

- 登録した候補からランダムに1つ選ばれます。
- 台詞は現在のキャラクターごとに保存されます。
- 編集画面に表示される `{duration}` などの変数は、実際の時間や結果へ置き換わります。
- 各場面で最低1つの台詞を残してください。
- `初期の言葉に戻す` で、その場面の既定値へ戻せます。

## ポモドーロを設定する

`設定 > ストップウォッチ発話 > ポモドーロ設定` で作業時間と休憩時間を設定します。

- 作業時間: 1〜120分
- 休憩時間: 1〜60分

対応デバイスへ接続して開くと、現在のデバイス設定を読み込みます。保存した変更はデバイスへ送信され、実行中のセッションは変更せず次回開始時から反映されます。未接続時や非対応デバイスではアプリ内だけに保存されるため、対応デバイスへ接続してもう一度保存してください。

## 画面OFF時の動作

対応ファームウェアが画面OFFを通知した場合、アプリは不要な再接続を繰り返さず通信休止として扱います。画面を戻したあと、再接続と状態同期が完了するまで少し待ってください。休止中に発生した読み上げは、期限切れや重複防止のため再生されない場合があります。

## うまく読み上げない場合

- `時間機能の発話` と TTS が有効か確認します。
- 接続中のデバイスが `timekeeper.v1` を通知しているか確認します。
- ポモドーロ設定が送れない場合は `timekeeper.pomodoro.v1` 対応を確認します。
- `発話量` が `静か` の場合は、`標準` または `にぎやか` でも試します。
- 画面OFFから戻した直後は、接続状態が戻ってから操作します。
- 同じイベントを再送しても、重複防止により同じ台詞をもう一度読み上げないことがあります。
