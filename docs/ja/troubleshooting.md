# トラブルシューティング

[READMEへ戻る](../../README.md) | [English](../en/troubleshooting.md)

## ｽﾀｯｸﾁｬﾝ本体が見つからない

- スマートフォンとｽﾀｯｸﾁｬﾝ本体が同じ Wi-Fi にいるか確認してください。
- SoftAP の場合、スマートフォンが Stack-chan の Wi-Fi に接続されているか確認してください。
- Host と Port を確認してください。SoftAP の既定は通常 `192.168.4.1:8080` です。
- iPhone の場合、ローカルネットワーク権限が許可されているか確認してください。
- VPN、プライベートリレー、モバイル通信優先設定が通信を妨げていないか確認してください。
- Android の USB Serial の場合は、USB ケーブル、Port 欄の baud rate、USB デバイスへのアクセス許可を確認してください。

## 接続はできたが会話できない

- LLM 設定を確認してください。
- 外部 API を使う場合は、API キー、Base URL、モデル名を確認してください。
- ローカル LLM を使う場合は、モデルファイルが選択されているか確認してください。
- ｽﾀｯｸﾁｬﾝ本体側の WebSocket サーバーが起動しているか確認してください。

## SoftAP接続中に外部APIだけ使えない

- スマートフォンのモバイルデータ通信が有効か確認してください。
- OS のモバイルデータ設定で `StackChan Pet Talk` の通信が許可されているか確認してください。
- 通信事業者の制限、VPN、プライベートリレー、ファイアウォールを一時的に切り分けてください。
- LAN 内、VPN、Tailscale、プライベート IP のサーバーはモバイルデータへ強制しません。スマートフォンからその接続先へ到達できる経路を確認してください。
- 外部 API の利用ではモバイルデータ通信量が発生する場合があります。

## Hermes Agentに接続できない

- `設定 > LLM > Hermes 接続確認` で表示される項目を確認してください。
- URL は Hermes のベース URL を指定し、`/api/sessions` など個別 API のパスを付けないでください。
- API キー、サーバーの `/health`、TLS 証明書、ファイアウォールを確認してください。
- 会話には `Sessions` と `SSE`、日記生成にはストリーミング Chat Completions が必要です。
- `Hermes Agent Memory` のみ `確認失敗` の場合は、toolsets API と memory toolset の設定を確認してください。
- 2 MBを超える画像はHermesへ送信できません。縮小してから添付してください。

詳しくは [Hermes Agent の使い方](hermes-agent.md) を確認してください。

## ローカルLLMを読み込めない

- LiteRT-LM は `.litertlm`、llama.cpp は `.gguf` が選択されているか確認してください。
- 画像を扱う場合は、メイン GGUF と同じモデル系統・同じ revision の `mmproj*.gguf` を選んでください。
- モデル選択後は取り込み完了を待ってください。問題が続く場合は、`取り込んだLLMファイルを削除` を実行してから選び直します。

## 音声認識できない

- 音声AI設定で ASR が選択されているか確認してください。
- ｽﾀｯｸﾁｬﾝ本体側からマイク音声が送られているか確認してください。
- 外部 ASR API を使う場合は、API キーとネットワーク接続を確認してください。
- PC 上のサーバーを使う場合、スマートフォンから見える LAN IP を指定してください。`localhost` はスマートフォン自身を指します。

## 音が出ない

- 音声AI設定で TTS が有効になっているか確認してください。
- ｽﾀｯｸﾁｬﾝ本体側のスピーカー再生が有効か確認してください。
- 音量、ミュート、接続状態を確認してください。
- TTS のモデルや外部 API 設定を確認してください。
- Style-Bert-VITS2 を使う場合は、iPhone で変換済みの BERT フォルダと VITS2 フォルダの両方が選択され、話者が選ばれているか確認してください。

## カメラや画像機能が動かない

- ｽﾀｯｸﾁｬﾝ本体側の `POST /capture` が使えるか確認してください。
- ｽﾀｯｸﾁｬﾝ本体の起動直後などでカメラがまだ初期化中の場合は、少し待ってから再試行してください。
- アプリのカメラ/写真権限が必要な機能では、権限設定を確認してください。
- スマートフォンの写真を会話に添付する場合は、画像対応 LLM と、llama.cpp では対応する `mmproj` が設定されているか確認してください。
- 画像の添付先は次に送信するメッセージです。画像を選んだあと、質問文を入力して送信してください。
- llama.cpp の画像処理が遅い、またはメモリ不足になる場合は、`設定 > LLM > VLM入力画像の最大辺` を小さくしてください。細部や小さい文字を認識しにくい場合は大きくしてください。
- `デバイスカメラ` が表示されない場合は、接続先がカメラ機能を通知していないか、カメラが利用できない状態です。

## 歩数・振った時の反応・吹き出しが動かない

- これらは対応ファームウェアと本体が通知する機能情報に依存します。
- 歩数あいさつは、`キャラ設定` で有効になっているか、しきい値や変化幅を満たしているか確認してください。
- 振った時の反応は、対応する shake/start イベントを本体から受信した時に動きます。
- 吹き出しは、本体が `display.speech_bubble.v1` に対応している場合だけ表示されます。
- `キャラ設定の管理` の `共通` と `デバイス別` を切り替えた場合は、現在の接続先に対応するキャラクター設定になっているか確認してください。

## ストップウォッチやポモドーロを読み上げない

- `設定 > ストップウォッチ発話 > 時間機能の発話` と TTS を有効にしてください。
- 接続中のデバイスが `timekeeper.v1` を通知しているか確認してください。
- ポモドーロ設定の送受信には `timekeeper.pomodoro.v1` が必要です。
- `発話量` が `静か` の場合は、`標準` または `にぎやか` でも確認してください。
- 画面OFFから戻した直後は、接続状態が回復するまで待ってください。
- 同じイベントの再送は、重複防止により読み上げない場合があります。

詳しくは [時間機能の発話](timekeeper.md) を確認してください。

## フィードバック時に書いてほしいこと

- 使用端末と OS バージョン
- アプリのバージョン
- 接続方式: SoftAP / Wi-Fi IP / USB Serial
- Host / Port
- 何をした時に起きたか
- 表示されたエラー
- 可能ならスクリーンショット
