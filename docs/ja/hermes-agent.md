# Hermes Agent の使い方

[READMEへ戻る](../../README.md) | [English](../en/hermes-agent.md)

`Hermes Agent` は、ユーザーが用意した Hermes API サーバーを StackChan Pet Talk の会話用 LLM として使う設定です。Hermes サーバーや API キーはアプリに同梱されません。

Hermes では、通常の LLM 応答に加えて、サーバー側で有効になっているスキル、ツール、Agent Memory を会話に利用できます。利用できる機能と保存期間は、接続先サーバーの構成に依存します。

## 設定する

1. `設定 > LLM` を開きます。
2. `プロバイダー` で `Hermes Agent` を選びます。
3. `Hermes URL` にサーバーのベース URL を入力します。`/api/sessions` など個別 API のパスは付けません。
4. サーバーで発行した `API Key` を入力します。
5. `Hermes 接続確認` を押します。
6. 必要な機能が確認できたら設定を保存し、会話画面へ戻ります。

インターネット越しに接続する場合は HTTPS を推奨します。信頼できるサーバーと API キーだけを使用してください。

## 接続確認の表示

接続確認では、サーバーの `/health`、capabilities、toolsets を使って次の項目を確認します。

- `Sessions`: 会話セッションの作成と取得
- `SSE`: 会話応答のストリーミング
- `Skills`: サーバー側スキル API
- `Hermes Agent Memory`: memory toolset が有効かつ設定済みか
- `ツール進捗`: ツールの開始、進行、完了状態
- `日記生成`: ストリーミング Chat Completions

会話には `Sessions` と `SSE` が必要です。Hermes を日記生成にも使う場合は `日記生成` も必要です。Skills、Agent Memory、ツール進捗はサーバー構成に応じた任意機能です。

`Hermes Agent Memory` が `確認失敗` の場合は、会話そのものが使えないとは限りません。サーバーの toolsets API、memory toolset の有効化、接続先プロファイルの設定を確認してください。

## 会話とツール

Hermes Agent を選んだ会話はサーバー側のセッションとして処理されます。ツール進捗に対応するサーバーでは、処理中の状態がアプリのイベント表示へ反映されます。

画像を添付する場合、Hermes へ送れる画像は1枚あたり2 MB未満です。大きい画像は縮小してから選び直してください。利用できる画像処理やツールはサーバー側の設定に依存します。

## Hermes 会話履歴

`設定 > LLM > Hermes 会話履歴` では、接続先サーバーに保存されたセッションを一覧表示できます。セッションを開くと、ユーザーとアシスタントのメッセージに加え、利用されたツールの詳細を確認できます。

ここに表示される履歴はアプリ内だけの履歴ではなく、Hermes サーバーから取得する情報です。削除方法、保持期間、管理者が閲覧できる範囲は接続先サーバーの運用方針を確認してください。

## プライバシー上の注意

Hermes Agent を選ぶと、入力テキスト、プロンプト、会話コンテキスト、画像、セッション情報が接続先へ送信される場合があります。サーバー側のスキルやツールは、設定に応じて別のサービスへアクセスしたり、Agent Memoryへ情報を保存したりする場合があります。

詳しくは [プライバシーポリシー](../../privacy/ja.md) を確認してください。

## うまく接続できない場合

- URL が `http://` または `https://` から始まる有効なベース URL か確認します。
- API キー、サーバーの稼働状態、証明書、ファイアウォールを確認します。
- SoftAP 接続中は、スマートフォンのモバイルデータ通信が有効か確認します。
- `Sessions` または `SSE` が非対応の場合は、Hermes サーバー側を更新または設定します。
- 日記生成だけ失敗する場合は、ストリーミング Chat Completions 対応を確認します。
